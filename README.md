# uniquelygaurab.github.io

The web side of [Minim](https://github.com/UniquelyGaurab/minim) share links.

- `/m/s#…` a shared song, `/m/p#…` a shared playlist. The page decodes the link in your browser; everything after the `#` never reaches a server.
- `/.well-known/assetlinks.json` lets Android open these links straight in Minim.

No analytics, no cookies, no third-party scripts. Covers load from i.ytimg.com.
